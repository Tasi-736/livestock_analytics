The original dataset is not bundled in this generated project because the GitHub archive
could not be downloaded in the authoring environment.

When the application starts, it first checks this folder for an active_dataset.* file and
then attempts the direct raw dataset URL used in the supplied Colab notebook.

If automatic download is unavailable, open the website's Data Source panel and upload:
- the repository ZIP from the GitHub archive link, or
- the original .csv.arff file, or
- a regular CSV with the expected columns.

The app accepts ZIP files containing an .arff or .csv file.
